# JavaScript Variable Showcase

A simple beginner-friendly website that displays JavaScript variables with three data types: a string, a number, and a boolean. The page is built with HTML and CSS, and the linked JavaScript file prints each value to the browser console and displays it on the page by its element ID.

## Live website

[Open the deployed website](https://andrybeltran.github.io/javascript-variables-site/) after GitHub Pages deployment is set up.

## Deploy with GitHub Pages

The `.github/workflows/deploy.yml` workflow deploys the site when changes are pushed to the `main` branch. Create a GitHub repository named `javascript-variables-site`, push this project to its `main` branch, then set the repository's Pages source to **GitHub Actions**. The workflow will publish the site at the link above.
